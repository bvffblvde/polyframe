# Add a skin

1. Create `src/core/skins/<id>.ts` exporting a `SkinDefinition`:
   - `tokens`: palette, radii, shadows, font, control heights, stroke width and focus ring. Take the values from the library's public default theme. Do not copy its CSS.
   - `vars`: per-component details such as button text transform, card shadow or navbar colors.
   - `structure`: structural flags (`inputLabel`, `tabs`, `switch`) for markup that really differs.
2. Add the id to `SKIN_IDS` in `src/core/document/types.ts` and to `skins` and `SKIN_LABELS` in `src/core/skins/index.ts`.
3. The CSS for every skin is generated by `buildSkinCss()`, so no stylesheet changes are needed unless the skin needs a new variable.
4. Check every component in the new skin in both modes, and link the library's license in the README disclaimer.
