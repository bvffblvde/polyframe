# Exporter check

Type-checks the code generated by Polyframe exporters for every starter template, target and layout strategy. It is a separate package so that real UI libraries never enter the app.

```bash
EXPORT_FIXTURE_DIR=exporter-check/generated pnpm vitest run src/core/exporters
pnpm --dir exporter-check install --ignore-workspace
pnpm --dir exporter-check check
```

`components/ui` holds shadcn/ui sources (MIT) from the shadcn registry.
